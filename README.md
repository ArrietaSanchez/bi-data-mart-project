# BI Data Mart Project

## Objective
Design and implement a dimensional Data Mart to support business analysis and decision-making.

## Project Overview
This project demonstrates the process of designing a Business Intelligence solution from data modeling to analytical insights.

## Components

### Data
Sample datasets used for analysis.

### SQL
Scripts used to create tables, transformations and analytical queries.

### Dashboard
Power BI dashboard for data visualization.

### Documentation
Explanation of the data model, KPIs and analytical findings.

## Tools
- SQL
- Power BI
- Python
- Pandas
- Data Modeling
